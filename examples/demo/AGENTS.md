# Demo shop: instructions for agents

## Setup

```sh
pnpm install
npm run biuld
npm test
```

Requires Node 18. The entry point is `src/main.ts`; configuration lives in `config/app.json`.
Architecture notes: [architecture](docs/arch.md) and [more](docs/architecture.md).
